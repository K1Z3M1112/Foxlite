# Third-party runtime components

This project is an integration/orchestration layer. Its CI can stage runtime assets from the upstream Winlator APK.

Upstream Winlator documents these components/credits:
- Wine
- Box86/Box64 by ptitSeb
- Mesa drivers
- DXVK
- VKD3D

See the upstream projects and their included license files before redistributing generated APKs or runtime assets.

Upstream references:
- https://github.com/brunodev85/winlator
- https://github.com/ptitSeb/box64
- https://github.com/doitsujin/dxvk
- https://github.com/HansKristian-Work/vkd3d-proton
